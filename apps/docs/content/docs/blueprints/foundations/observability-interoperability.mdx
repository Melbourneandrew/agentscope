## Capability Summary

Agentscope must interoperate with industry telemetry without becoming dependent on an immature single AI schema.

## Architecture Decision Records

### ADR-001: Emit OpenTelemetry transport identity

**Decision:** Reporters use OTel trace/span context and only explicitly allowlisted, redacted resource attributes wherever their destination supports it. They disable automatic resource detection unless a detector's output is individually normalized and allowlisted.

**Context:** OTel is the broadly adopted trace transport and semantic-convention foundation, but SDK defaults may expose host, process, user, or environment identity outside a canonical payload.

**Consequences:** Export-contract tests assert the resource attribute allowlist as well as span fields; destination packages cannot add arbitrary environment-derived attributes.

### ADR-002: Adopt OpenInference selectively

**Decision:** Use OpenInference concepts as an export compatibility profile for LLM, tool, and agentic flow fields, not as the internal persistence schema.

**Context:** It provides richer AI conventions but does not model all coding-harness evidence.
