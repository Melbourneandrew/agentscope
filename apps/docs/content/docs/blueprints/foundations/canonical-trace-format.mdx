title: Canonical Agentscope Trace Format
description: ADRs for the lossless cross-harness event model.

## Capability Summary

Agentscope needs a durable internal trace format that preserves coding-agent evidence while supporting interoperable export.

## Architecture Decision Records

### ADR-001: Keep Agentscope canonical and lossless

**Decision:** `@agentscope/core` owns the versioned canonical trace contract. It evolves the SF Platform-derived model as its starting provenance rather than making an external telemetry schema the source of truth.

**Context:** Coding harnesses expose transcripts, turn journals, skill reads, workspace context, and trace-to-code attribution that external conventions do not consistently model.

**Consequences:** The public plugin ABI names a versioned `CanonicalTraceEnvelope` in `@agentscope/core`; current `NativeAgentTrace`, `TraceBatch`, and Agent Trace records are migrated behind it before third-party ABI stabilization. Core owns compatibility rules and migrations.

### ADR-002: Redact before canonical durability

**Decision:** Raw native artifacts are transient adapter input only. Redaction occurs before a canonical envelope, source provenance, unknown field, raw pointer, spool entry, diagnostic, or reporter payload becomes durable.

**Context:** “Lossless” must preserve observability semantics, not retain secrets. Requirements prohibit sensitive data from reaching persistence or destinations.

**Consequences:** A raw pointer is a sanitized identity/reference, never an address to unredacted retained content. Fields that cannot be safely represented after redaction are omitted with a bounded unavailable/redacted reason.

### ADR-003: Use versioned export profiles for interoperability

**Decision:** Map canonical traces to version-pinned OpenTelemetry GenAI and OpenInference profiles at reporter boundaries.

**Context:** OTel GenAI agent conventions are emerging and still development-status; OpenInference supplies complementary LLM, tool, and agent conventions.

**Consequences:** Standards churn changes one mapper, not every harness. Agentscope exports W3C/OTel-compatible trace identity while retaining fields those profiles cannot represent.
