## Capability Summary

Native artifacts vary by harness; this Blueprint defines how adapters map them without fabricating certainty.

## Architecture Decision Records

### ADR-001: Preserve provenance and uncertainty

**Decision:** Every canonical field derived from a native artifact records source/provenance where ambiguity affects interpretation, and unavailable values remain unavailable.

**Context:** Transcript data, hook payloads, and process working directories can disagree or be incomplete.

**Consequences:** Git branch resolution follows authoritative hook workspace, native session workspace, then process cwd; detached and unavailable states are explicit.

### ADR-002: Normalize semantic primitives, retain native evidence

**Decision:** Map sessions, turns, model calls, tools, skills, files, errors, and child agents to shared primitives while retaining only sanitized raw-source identities after the transient adapter phase.

**Context:** Consumers need portable semantics and support engineers need a way to explain mappings, but raw native content cannot cross the redaction boundary.

**Consequences:** A harness adapter emits OpenInference `AGENT`, `LLM`, `TOOL`, and other applicable OTLP spans directly. It contributes `agentscope.*` only for harness/Git/workspace/provenance concepts; model, message, token, timing, and error fields use their OpenInference definitions rather than duplicate fields.
