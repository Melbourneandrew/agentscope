# Agent Harness Integration Testing

## Capability Summary

This Blueprint records the test architecture that fulfills [Harness Management](/docs/requirements/harness-management), [Trace Capture](/docs/requirements/trace-capture), and [Data Governance and Reliability](/docs/requirements/data-governance-and-reliability).

## Architecture Decision Records

### ADR-001: Test real agent harness executables

**Decision:** Integration tests run the actual supported harness executable, not only transcript replay fixtures.

**Context:** Hooks, configuration precedence, command flags, and native artifact behavior can drift independently of parsers.

**Consequences:** Each supported version has a detection/compatibility recipe. Missing local optional binaries may skip locally; CI pins required images and versions.

### ADR-002: Isolate every scenario

**Decision:** Each scenario uses a disposable `AGENTSCOPE_HOME`, harness home, Git workspace, and ephemeral loopback endpoints.

**Context:** Tests must never read a developer's configuration, credential store, repository, or paid destination account.

**Consequences:** Scenarios can assert branch/worktree context and installation reversibility without cross-test state.

### ADR-003: Use protocol-aware mock boundaries

**Decision:** The testkit hosts deterministic protocol slices for OpenAI/Responses, Anthropic, and Gemini model traffic plus a mock OTLP/Langfuse collector with request ledgers.

**Context:** A universal mock hides protocol drift; separate per-harness servers duplicate assertion infrastructure.

**Consequences:** Harness adapters contribute versioned setup/invocation/expectation recipes. The generic runner asserts model traffic, native artifacts, normalized traces, and destination payloads.

### ADR-004: Separate hermetic and live validation

**Decision:** Unit and hermetic integration tests gate pull requests; a protected scheduled/manual live Langfuse smoke validates external drift.

**Context:** Paid or network-dependent services are unsafe and flaky as normal PR gates.

**Consequences:** Live tests use protected credentials and never replace the local mock matrix.
