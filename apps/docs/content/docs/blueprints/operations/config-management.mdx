## Capability Summary

This Blueprint realizes [Configuration Directory](/docs/requirements/configuration-directory) for a TypeScript CLI.

## Architecture Decision Records

### ADR-001: Resolve one cross-platform machine-local root

**Decision:** Resolve the default home with Node's `os.homedir()` and `path.join(home, ".agentscope")`: `~/.agentscope` on macOS/Linux and `%USERPROFILE%\\.agentscope` on Windows. `AGENTSCOPE_HOME` is the only explicit override and replaces the entire resolved home for tests, CI, and portable installs.

**Context:** Users and hook processes need a predictable support surface without Unix-only path assumptions; hermetic tests need one clean override.

**Consequences:** Every CLI command, hook, Core service, and harness adapter receives the same injected home resolver. No package derives its own path from `$HOME`, `~`, a shell expansion, or a platform-specific environment variable.

### ADR-002: Persist atomically and version configuration

**Decision:** Validate versioned config, write a same-directory temporary file, fsync where supported, then atomically rename; migration makes a bounded backup first.

**Consequences:** Hooks fail open on quick lock contention and never perform interactive migration.
