## Capability Summary

Configuration must accommodate new packages without converting `config.json` into an untyped global bag.

## Architecture Decision Records

### ADR-001: Namespace destination configuration by stable package identity

**Decision:** Core owns the top-level version, configured destinations, and cross-destination routing/selection policy; each first-party Trace Destination package owns only its schema-validated local configuration block.

**Context:** New first-party reporters and harnesses need configuration without collisions or core releases for every option. Agentscope does not load third-party executable packages at runtime.

**Consequences:** A Trace Destination declares its reporter/retriever capabilities and local destination settings. Core alone selects which named destination or destinations receive a canonical batch, resolving the active-connection behavior in REQ-CONN-002.

### ADR-002: Preserve unknown package blocks

**Decision:** Older CLIs preserve unknown first-party package namespaces during read/write and refuse unsafe downgrades.

**Context:** A user may update one package before the CLI; losing its settings is worse than an actionable compatibility error.
