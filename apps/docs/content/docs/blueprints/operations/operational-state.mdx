title: Operational State
description: ADRs for minimal diagnostics and recoverable state.

## Capability Summary

Core owns only the small operational state needed to diagnose installations and recover configuration changes. It never uses machine-local state as a deferred trace-delivery system.

## Architecture Decision Records

### ADR-001: Keep trace data out of operational state

**Decision:** `AGENTSCOPE_HOME` may contain versioned configuration, configuration-migration markers, short-lived locks, and bounded sanitized diagnostics. It shall not contain raw native artifacts, canonical trace graphs, pending batches, reporter payloads, credential values, or a retry queue.

**Context:** A hook must fail open when reporting is unavailable. Persisting failed telemetry would create an unrequested local trace repository with privacy, retention, encryption, and recovery obligations.

**Consequences:** A hook reports once within its deadline. On any failed or incomplete delivery it discards the batch and records only a stable error code, timestamp, destination identity, and bounded non-sensitive summary.

### ADR-002: Bound diagnostics and make loss explicit

**Decision:** Sanitized diagnostics have explicit size, age, and entry-count limits with deterministic eviction. Doctor reports their status and loss count; it cannot replay or reveal a discarded trace.

**Context:** Diagnostics must aid support without becoming a covert event store or consuming a machine indefinitely.

**Consequences:** `agentscope doctor` may safely repair stale Agentscope-owned locks and incomplete configuration migrations. It does not offer delivery replay, trace inspection, or arbitrary cleanup.

### ADR-003: Make configuration-state migrations recoverable

**Decision:** Core performs configuration-state migrations side by side: it writes and validates a new versioned area, atomically switches a small active-version marker, and retains the prior area through a documented compatibility window.

**Context:** A process can stop between writing, validating, and committing an upgrade.

**Consequences:** Doctor reports stale locks and incomplete migrations with stable diagnostics. Recovery never needs to reinterpret historic trace payloads because none are retained.
