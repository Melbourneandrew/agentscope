## Capability Summary

Hook installation writes the minimal owned integration that allows a harness to invoke Agentscope capture.

## Architecture Decision Records

### ADR-001: Use identifiable owned blocks and transactions

**Decision:** Adapters generate an identifiable Agentscope-owned block, snapshot the target configuration, validate the result, then commit atomically where the host format permits.

**Context:** Uninstall and rollback must never remove user-managed configuration.

### ADR-002: Detect conflicts before modifying hooks

**Decision:** An adapter reports overlapping Agentscope/vendor hooks and requires explicit migration or replacement authority.

**Consequences:** Dry-run is the default diagnostic path; failure rolls back the full installation transaction.

### ADR-003: Verify installation in fresh machine-like environments

**Decision:** The integration matrix installs the packed CLI and each harness adapter into a fresh isolated container before exercising its owned hook.

**Context:** A developer's globally installed binary or preexisting harness configuration can hide missing package assets, installation assumptions, or upgrade regressions.
