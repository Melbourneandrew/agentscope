Unconfiguration removes the connection and its routing selection atomically. It never deletes a Local SQLite database or other destination-owned data. Local SQLite first returns a read-only retention plan; `--yes` presents the plan, preserves the database unchanged, and returns the opaque retained-delete selector needed by a later fresh process. By default, stored credentials and the configuration backup are retained. Explicit `--retire-credentials` requests the canonical complete-connection retirement: both configuration reference sets must be proved free before deleting the exact owned stored set. Partial or uncertain proof does not permit deletion.

## Syntax

```bash
agentscope destination unconfigure <name> [--yes] [--retire-credentials] [--output human|json|jsonl]
```

## Output and exits

For Local SQLite, without `--yes`, `human`, `json`, and `jsonl` report the plan with `applied: false`. On apply they report the committed generation, `dataPreserved: true`, and the retained selector using `agentscope.cli.destination-unconfigure.v1`. Other connections are unconfigured directly. Stored retirement never implies destination data deletion.

## Automation

This command is safe for local data retention but is not equivalent to data deletion. Use the separate confirmed delete command for an exact owned file.

The original foreground 60-second allowance includes all credential work; cancellation and expiry do not start a fresh cleanup window. A fixed failure may retain committed or uncertain work for reconciliation. `--retire-credentials` is not a rotation operation and is not applicable to Local SQLite.

## Diagnostics

- `configuration.conflict` and `configuration.unavailable` describe the atomic write.
- `destination.connection-missing` rejects an unknown name.
- `destination.credential-removal-required` prevents orphaning a referenced credential.
- `destination.lifecycle-busy`, `destination.lifecycle-outcome-unknown`, `destination.lifecycle-reconciliation-required`, and `destination.lifecycle-unavailable` are closed Local lifecycle outcomes.

## Examples

```bash
agentscope destination unconfigure local-history --yes
```
