The generic configure command resolves `<type>` through the compiled first-party registry, validates non-secret settings with the descriptor's detached strict schema, validates every declared credential slot, and commits one new configuration generation atomically.

Langfuse and Local SQLite are registered first-party types. In the 0.1.0 alpha, Local SQLite remains discoverable but cannot be configured: both planning and `--yes` return `destination.capability-unavailable` before a plan, filesystem write, or configuration mutation. Local SQLite lifecycle support requires a later, independently admitted release.

## Syntax

```bash
agentscope destination configure <type> --name <name> [--settings <json>] [--credential-env <slot=VARIABLE...>] [--yes] [--output human|json|jsonl]
```

## Output and exits

For an admitted destination, `--yes` presents its plan before mutation; machine modes write that plan to standard error. The applied `json` and `jsonl` result contains exactly one public connection record with `connectionId`, `destinationType`, `name`, `routed`, `settingsVersion`, and `transport`. `human` output reports the configured connection and configuration generation. Every mode derives from `agentscope.cli.destination-configure.v1`. Credential values are never output.

## Automation

Unknown settings, duplicate slots, missing required slots, credential-shaped settings, and an unavailable or malformed referenced variable fail before the atomic write. `--credential-env` resolves only the exact named variable for preflight and stores only its CI environment reference; the credential value is never copied into configuration, output, or diagnostics.

## Diagnostics

- `configuration.conflict`, `configuration.missing`, and `configuration.unavailable` describe the Core configuration boundary.
- `destination.connection-exists` rejects duplicate names.
- `destination.capability-unavailable` rejects 0.1.0 alpha Local SQLite configuration before a plan or mutation.
- `destination.credential-unavailable` means a declared CI credential reference could not be safely resolved before mutation.
- `destination.lifecycle-busy`, `destination.lifecycle-outcome-unknown`, `destination.lifecycle-reconciliation-required`, and `destination.lifecycle-unavailable` are closed Local lifecycle outcomes.
- `destination.type-missing` rejects a type absent from the first-party registry.

## Examples

```bash
agentscope destination configure local-sqlite --name local-history
agentscope destination configure local-sqlite --name local-history --yes
```

Both Local SQLite examples return `destination.capability-unavailable` in 0.1.0; they do not create a local trace database.
