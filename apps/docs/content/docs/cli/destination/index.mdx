Destination commands operate on named connections described by reviewed first-party descriptors. Core owns the outer configuration document, credential references, and routing invariants; provider packages never own terminal output or configuration transactions.

The packed CLI registers Langfuse and Local SQLite descriptors. Langfuse uses the remote descriptor path. Local SQLite is deferred from 0.1.0; its configuration and lifecycle operations are unavailable before mutation in the alpha. Descriptor registration does not claim Local Reporter, Retriever, or platform support.

## Syntax

```bash
agentscope destination <configure|list|inspect|unconfigure|delete|recover|rotate>
```

## Output and exits

Group help uses `human`. Leaf commands additionally support their declared machine modes and fixed diagnostic-to-exit mapping.

## Automation

Configuration accepts non-secret JSON and explicit CI environment references. Secrets are never accepted as settings or rendered in results. Local configuration and retention plans are shown before `--yes`; local data deletion is separate from unconfiguration and always requires `--confirm`. Recovery is a separate explicit command and Doctor never applies it.

## Diagnostics

Leaf command pages list their exact fixed diagnostics. Group parsing failures use the root `cli.usage` contract.

## Examples

```bash
agentscope destination list
```
