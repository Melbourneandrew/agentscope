The 0.1.0 alpha does not admit Local SQLite. This registered command therefore
returns `destination.lifecycle-unavailable` before producing a recovery plan
or mutating state. Its syntax is reserved for future admitted lifecycle work;
Doctor does not recommend or run an unavailable recovery operation.

## Syntax

```bash
agentscope destination recover [--yes] [--output human|json|jsonl]
```

## Output and exits

For 0.1.0, no planned or applied-success output is available in `human`,
`json`, or `jsonl` mode.

## Automation

`--yes` does not make an unavailable lifecycle capability available.

## Diagnostics

- `configuration.conflict`, `configuration.missing`, and `configuration.unavailable` describe the Core configuration boundary.
- `destination.lifecycle-busy` means a lifecycle owner or lock still holds authority.
- `destination.lifecycle-capacity` reports a bounded maintenance capacity failure.
- `destination.lifecycle-outcome-unknown` and `destination.lifecycle-reconciliation-required` are closed lifecycle outcomes.
- `destination.lifecycle-unavailable` means no admitted handler or stable inspection authority is available.

## Examples

The following syntax remains unavailable in 0.1.0:

```bash
agentscope destination recover
```
