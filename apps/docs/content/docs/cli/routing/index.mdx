Routing is a Core-owned list of exact configured connection identities. Harness extraction is independent of destination choice, and no configured connection is selected implicitly.

## Syntax

```bash
agentscope routing <list|set>
```

## Output and exits

Group help uses `human`. Leaf commands support `human`, `json`, and `jsonl` with versioned schemas.

## Automation

An empty selection is valid and disables delivery. Unknown and duplicate names are rejected before hook-time delivery.

## Diagnostics

Leaf pages list the exact configuration and routing diagnostics. Group parsing failures use `cli.usage`.

## Examples

```bash
agentscope routing list
agentscope routing set primary archive
```
