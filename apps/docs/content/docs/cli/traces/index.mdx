Trace commands query exactly one configured destination. They never use routing selection, fall back to another connection, or expose destination-native response bodies.

Core starts one fixed two-second absolute retrieval deadline at command entry, before configuration is read. This retrieval budget is independent of the configurable capture-hook deadline and bounds configuration, credential, transport, and Retriever work together.

## Syntax

```bash
agentscope traces search --destination <name> [options]
agentscope traces get --destination <name> (--trace-id <id> | --trace-ref <json>)
```

## Output and exits

The group exposes `human` help. Search and get support their documented `human`, JSON, and JSON Lines result contracts.

## Automation

Always pass `--destination`. Preserve search cursors and structured locators verbatim; both are bound to the selected immutable connection and current configuration.

## Diagnostics

Subcommands return fixed `traces.*` diagnostics without provider response bodies, credentials, paths, or stack traces.

## Examples

```bash
agentscope traces search --destination archive --harness codex
agentscope traces get --destination archive --trace-id 0123456789abcdef0123456789abcdef
```
