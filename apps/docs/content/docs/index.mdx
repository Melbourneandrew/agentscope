---
title: Agentscope
description: Safe trace observability for coding-agent CLIs.
---

Agentscope installs reversible coding-agent integrations, converts native
lifecycle events into portable OpenTelemetry/OpenInference traces, and sends
them only to destinations you explicitly configure and select.

## Current status

Agentscope 0.1.0 is not published yet. Final actual-binary CI evidence has
passed for Codex 0.149.1 and Claude Code 2.1.245 in Linux x64 CI execution with
Node.js 22, interactive semantic-PTY capture, Langfuse OTLP, and explicit
environment-variable credential references. These remain candidate evidence,
not published support rows, until the governed product support manifest,
release record, and package publication are complete. See
[Getting started](./docs/getting-started) for the exact rows and safe setup
sequence.

Claude Code capture covers `SessionStart`, `PreToolUse`, `PostToolUse`, and
`Stop`; it does not claim `SessionEnd` or a native end event. macOS, Keychain,
workstation execution, Local SQLite, Cursor, and the remaining product-roster
harnesses are not 0.1.0 support claims.

## Start here

1. Read [Getting started](./docs/getting-started) for the publication status and
   safe setup sequence.
2. Use the [CLI reference](./docs/cli) for exact commands, output modes, and
   diagnostics.
3. Read the [requirements](./docs/requirements/product-description) for product
   behavior and the [workspace Blueprint](./docs/blueprints/foundations/workspace-architecture)
   for an entry point to internal architecture.

Agentscope never selects a destination implicitly, replaces an overlapping
observability hook during ordinary installation, or treats an unadmitted
harness or platform as supported.
