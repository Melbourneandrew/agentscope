AgentScope captures traces from coding-agent CLIs and forwards normalized events to destinations such as Langfuse.

## Planned quick start

```bash
npx @agentscope/cli init
agent-scope configure reporter langfuse
agent-scope install codex
```

The documentation site is scaffolded with a standard Next/Fumadocs dependency stack. Guides and navigation are the next documentation slice.
