---
title: Agentscope
description: Safe trace observability for coding-agent CLIs.
---

Agentscope installs reversible coding-agent integrations, converts native
lifecycle events into portable OpenTelemetry/OpenInference traces, and sends
them only to destinations you explicitly configure and select.

## Current status

Agentscope 0.1.0 is not published yet. Codex and Claude Code are the target
harnesses for the first alpha, but public support begins only after packed-CLI
actual-binary admission. Cursor and the remaining product-roster harnesses are
later work and do not block 0.1.0.

The current source-built CLI exposes the stable command surface and the Langfuse
and Local SQLite destination descriptors. Its packed harness registry remains
empty until admission completes.

## Start here

1. Read [Getting started](./docs/getting-started) for installation status and the
   safe setup sequence.
2. Use the [CLI reference](./docs/cli) for exact commands, output modes, and
   diagnostics.
3. Read the [requirements](./docs/requirements/product-description) for product
   behavior and the [workspace Blueprint](./docs/blueprints/foundations/workspace-architecture)
   for an entry point to internal architecture.

Agentscope never selects a destination implicitly, replaces an overlapping
observability hook during ordinary installation, or treats an unverified harness
as supported.
